# CS 315 Week 1 Tasks

Notebooks and code for Week 1 tasks in CS 315 Fall 2026.

There are three tutorials:

1. Tutorial 1: Working with files in Python
2. Tutorial 2: Working with JSON data in Python
3. Tutorial 3: Working with CSV files in Python

Each folder has a notebook where you can enter the code from the tutorial.

Once you have completed each tutorial and understood the material, take the corresponding quiz linked in the tutorial or in our Google Doc with the Week 1 Tasks.
